{{- /* Returns the absolute URL of the preview image for a page (Open Graph and Twitter/X cards). - If the page sets `images` in front matter, the first one is used (a page resource or a site path). - Otherwise a card is generated: the page title in ITC Clearface and a kicker in STK Gerhard, on Fersken 20 with the emblem in Aubergine (light-mode colours from the National Library's profile manual). Base image: assets/images/og/base.png. Fonts: assets/fonts/ (TrueType, build-time only, not published). */ -}} {{- $page := . -}} {{- $url := "" -}} {{- with $page.Params.images -}} {{- $first := index . 0 -}} {{- with $page.Resources.GetMatch (strings.TrimPrefix "/" $first) -}} {{- $url = .Permalink -}} {{- else -}} {{- $url = $first | absURL -}} {{- end -}} {{- else -}} {{- $url = (partial "og-card.html" $page).Permalink -}} {{- end -}} {{- return $url -}}
